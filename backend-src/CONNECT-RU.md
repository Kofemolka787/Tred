# TRED 0.4.3 — сигналы и сборщик

Полный ZIP содержит сервер, интерфейс и расширение **0.4.3**. Обнови все три части. Личная база, ключ LunaRoute и подтверждённые профили находятся вне ZIP и сохраняются.

В 0.4.3 сборщик поддерживает графики готовыми **между запросами**. Новый сигнал не перезагружает служебную вкладку и не меняет её соединение. Для выбранного рынка заранее собираются M1, M5 и M15; ручная пара получает приоритет. Сбор рынка не вызывает ИИ и не расходует его кредиты.

## Обычный запуск — один файл

1. Открой **`START-WINDOWS.cmd`**. Он запустит сервер и доступ для Telegram, затем покажет окно **«TRED · запуск»** со статусом сохранённой модели. Повторная установка неизменившихся библиотек пропускается после проверки.
2. Нажми **«Открыть бота · адрес скопируется»**. Если после перезапуска изменился внешний адрес, вставь его только в кабинете бота. На телефоне подключение подтянется через Telegram. Расширение на этом ПК автоматически найдёт сервер по постоянному локальному адресу и сохранённому ключу связи.
3. В боте выбери пару либо автопоиск, 5/10/15 минут и нажми **«Получить сигнал»**. Запрос к LunaRoute отправится сам с сохранённым ключом. Отдельно запускать нейросеть, CLI или SETUP при каждом старте не нужно.

Оставь окно TRED и Pocket Option открытыми. **«Остановить и закрыть»** завершает свой сервер и туннель. Закрытие служебной вкладки приостанавливает фоновый сбор; новый запрос сигнала может его возобновить. Установка расширения, первая привязка кабинета и первая настройка ИИ нужны один раз. Если ключа ещё нет, в окне запуска есть **«Настроить ИИ один раз»**.

Текущая бесплатная схема работает на твоём компьютере. Внешний адрес Cloudflare может меняться; пока постоянный адрес не настроен, вставка нового адреса в боте остаётся необходимой. Расширение больше не требует переноса внешнего адреса. Обычный запуск не отправляет сообщений пользователям Telegram.

## Новый сбор истории

После получения каталога расширение открывает **одну служебную вкладку Pocket Option в фоне**, ещё до запроса сигнала. Страница входит через текущую сессию браузера и получает каталог. Пароль и сессия не копируются в TRED. На этой вкладке модуль запрашивает начальные графики через `changeSymbol`, затем подписывается на цены через `subfor`. Это тот же протокол получения графиков, который используют открытые библиотеки. Прежний `loadHistoryPeriod` остаётся для догрузки и последних тиков: одного этого запроса может быть недостаточно.

Основная вкладка остаётся для ручной работы с брокером. Команды смены графика разрешены только на вкладке, созданной самим расширением; на ней показана полоса TRED. Не открывай в служебной вкладке сделки вручную: её график меняется автоматически. Модуль не отправляет торговых команд.

Закрытие служебной вкладки останавливает её сбор; текущая проверка не будет открывать её снова по кругу. Следующий новый запрос сигнала сможет создать новую. Новый анализ использует существующую вкладку без перезагрузки. Только реальная смена соединения требует истории нового канала. Если она показывает вход в брокер, сначала войди в Pocket Option в этом браузере. «Остановить проверку» отменяет анализ; фоновое обновление графиков продолжается. Для приостановки сбора закрой служебную вкладку.

Обработчик истории заново проверен для `updateHistory`, обычных и Fast-событий, вложенных Socket.IO-вложений, отдельных JSON-ответов с точным индексом запроса, колонок OHLC и тиков `[время, цена, null]`. Инструмент и период не подбираются по порядку прихода. Закрытие свечи не выдаётся за текущую котировку.

Догрузка коротких страниц сохранена: если брокер прислал, например, 24 свечи вместо 80, модуль запрашивает более старые участки и объединяет настоящие свечи по исходным меткам. Пропуски не заполняются. Неполные совместимые M2/M10 догружаются без переключения на пустые M5/M15. Устаревшая история сначала запрашивается на текущее время. В каталоге отдельно видны действительно сохранённые непрерывные свечи каждого полученного периода и возраст последней закрытой свечи; число «распознано» в ответе брокера не означает, что весь график уже сохранён и готов.

## Обновить установленный TRED

1. Скачай [полный ZIP 0.4.3](https://kofemolka787.github.io/Tred/tred-backend-v0.4.3.zip). Правой кнопкой → «Извлечь всё». Скопируй содержимое `TredBackend` с заменой файлов в прежнюю папку, включая `SHA256SUMS.json` и всю папку `connector`.
2. В старом окне сервера нажми **Ctrl+C**, затем открой новый `START-WINDOWS.cmd`. Не запускай два сервера одновременно. Заново настраивать ключ ИИ не нужно.
3. На `opera://extensions` или `chrome://extensions` обнови **прежнюю карточку TRED** круглой стрелкой. Должна появиться **0.4.3**. В сведениях карточки указан путь: новые файлы `connector` должны лежать именно там. Удалять расширение не нужно.
4. Один раз обнови вкладку Pocket Option, чтобы новый модуль получил текущий каталог и историю.
5. В Telegram открой меню приложения ⋯ → **«Перезагрузить»**.
6. Если запуск выдал другой `https://…trycloudflare.com`, сохрани новый адрес только в кабинете бота. Расширение на этом ПК переходит на локальный сервер автоматически с прежним ключом связи. При прежнем адресе и сохранённой связи повторная привязка не нужна. Новый код используется только для изменённого или отклонённого подключения.

Не нажимай «Отключить связь» для обновления: это отзывает привязку и очищает снимки счёта. Не удаляй `%LOCALAPPDATA%\TRED\data`: там база и настройки. Повторно подтверждать Pocket ID для обновления не нужно.

## Как получить сигнал

Оставь компьютер, сервер и Pocket Option открытыми. Выбери обычный либо OTC-рынок и **5, 10 или 15 минут**. Каталог содержит все полученные инструменты; в поиск идут открытые пары с подходящими выплатой и длительностью. По умолчанию порог выплаты 85%, приоритет — 92%; сохранённый порог не сбрасывается.

Для более частых сценариев выбери **«Режим поиска → Чаще · ранние входы, повышенный риск»**. Продолжение тренда не требует нового отката, импульсный пробой не требует ретеста, а поглощение требует касания известного уровня или EMA. Переходный старший период допускается при отсутствии сильного встречного тренда. Частота не означает большую вероятность выигрыша. Прежний режим **«Строже»** сохраняется отдельно.

Нажми **«Получить сигнал» один раз**. При холодном каталоге расширение получает историю автоматически. Для графика нужны минимум 80 последних непрерывных закрытых свечей на двух совместимых периодах. Если рынок загружен частично, через 12 секунд ИИ запускается при наличии хотя бы одного подходящего сценария. Если на первых графиках сценария нет, бот продолжает проверять поступающие графики остальных пар. Полный рынок или достижение ограниченного срока ожидания завершают сбор; окончательный ответ может быть отказом. Графики продолжают обновляться и между проверками.

**ИИ анализирует закрытые графики.** Отсутствие текущей цены больше не скрывает полноценный закрытый график от модели. Инструменты без истории остаются в списке с причиной отсутствия данных. Число строк каталога и число действительно переданных графиков показываются отдельно.

**Проверяем цену входа.** После выбора сценария сервер при необходимости запрашивает свежую котировку именно выбранной пары. До неё направление входа и кнопка отметки сделки не показываются. Закрытие свечи никогда не используется вместо текущей цены. Для этой проверки не отправляется повторный платный запрос ИИ.

После проверки появляются пара, направление, длительность, зона и окно входа, ориентировочное время завершения и объяснение. Ранние active-сценарии могут пережить закрытие новой свечи в ограниченном окне (M1 — до двух минут после сигнального закрытия), если неизменны исходные 12 свечей, канал, зона, направление и условие отмены. Это повторная проверка исходного сценария, а не подмена новым. Если цена ушла, история изменилась или котировка не поступила, вход пропускается с причиной. Время внешнего ответа и холодной загрузки не гарантировано. Тестовые секунды не являются обещанием скорости реального сервиса.

«Готовы к анализу» означает проверенный закрытый график. «Свежие котировки» — отдельный показатель. Получение всего каталога не означает наличие графика каждой пары; приложение показывает фактический охват.

## Стратегии и роль ИИ

Проверяются пять семейств: **Smart Money и структура**, **откат EMA 20/50**, **пробой и ретест**, **отскок в диапазоне**, **ложный пробой**. У тренда и боковика отдельные условия. RSI, MACD, Stochastic, Bollinger Bands и поглощение дополняют сравнение; одного значения индикатора недостаточно.

Сервер вычисляет причинные признаки и передаёт их вместе с закрытыми графиками модели. LunaRoute/DeepSeek выбирает пару, направление и стратегию либо объясняет ожидание. После ответа заново проверяются свежая цена, та же зона и условия сценария. Новая свеча не отменяет неизменную подтверждённую SMC-зону автоматически, но требует полного повторного подтверждения. Свечные стратегии относятся к конкретной сигнальной свече.

Периоды заданы в секундах: **60=M1, 120=M2, 300=M5, 600=M10, 900=M15**. Длительность сделки отдельно задана в минутах. Для 15 минут предпочтительны M5+M15; поддерживаются прежние совместимые варианты при полной проверенной истории.

[Правила и слабые места стратегий](STRATEGIES-RU.md). Это настройка контекста и правил вокруг модели, а не обучение её весов. Прибыльность здесь не измерена. Выплата брокера не является вероятностью выигрыша; OTC-свечи не доказывают наличие биржевых заявок или стопов.

## Отметить вход и следить с телефона

После самостоятельного открытия сделки у брокера нажми **«Я открыл сделку»** и выбери счёт. Фактическую цену можно указать вручную. Кнопка записывает отметку и запускает наблюдение, а не отправляет ордер.

Тот же Telegram-пользователь видит движение цены и время завершения на телефоне, пока компьютер, сервер и брокер работают. Пропуски и устаревшие цены отмечаются; другой Telegram ID получает отдельный кабинет.

После окончания длительности отметь **плюс, минус или возврат**. Результат и объяснение сохраняются в журнале. Пользовательская отметка не меняет брокерский баланс и не становится проверенной статистикой брокера.

## LunaRoute и OpenAI

Если LunaRoute уже настроен, ничего не вводи заново. Для первой настройки запусти **`SETUP-LUNAROUTE.cmd`**, введи ключ локально и выбери модель из настоящего каталога, например доступную тебе `deepseek-4.1-flash`. Как просил владелец, ввод ключа видим в терминале. Короткий проверочный запрос расходует немного кредитов; настройки сохраняются после проверенного ответа.

Прямой OpenAI доступен через `SETUP-AI.cmd`. Подписка ChatGPT и API оплачиваются отдельно; LunaRoute использует свои кредиты. При ошибке нет скрытого переключения провайдера или сигнала от одних правил. Другой Telegram-пользователь не получает право тратить твой ключ автоматически.

Ключ хранится в личной папке и используется сервером для HTTPS к `https://gw.lunaroute.com/v1` либо `https://api.openai.com/v1`. Он отсутствует в Telegram, интерфейсе, ZIP и GitHub. Не присылай ключ, пароль, cookies или сессию брокера в чат и не включай их в скриншоты.

Модель получает только рыночные данные, без баланса, Pocket ID, Telegram ID и учётных данных. Большой каталог обрабатывается ограниченными пакетами с последующим сравнением сценариев. Короткий фрагмент OHLC дополняет признаки, рассчитанные по исходным 80–160 свечам.

Принимается только завершённый проверяемый ответ Responses API. Частичный JSON, неподдерживаемые стратегии и выдуманные ссылки не становятся входом. Тайм-аут, DNS, TLS, HTTP401/402/403/404/429 и ошибка формата различаются; сырой ответ провайдера не показывается. После ошибки платный запрос автоматически не повторяется.

## Подключение с нуля

Для Windows нужен Python 3.12+ x64. Распакуй весь архив и запусти `START-WINDOWS.cmd`. Установка использует личную папку пользователя без прав администратора и без записи окружения в защищённую папку с ZIP. Дождись адреса сервера.

В кабинете TRED вставь HTTPS-адрес и получи одноразовый код на пять минут. На странице расширений включи режим разработчика и загрузи распакованную папку `connector`. В TRED CONNECT оставь предложенный локальный адрес `http://127.0.0.1:8790` и введи код из кабинета, затем обнови Pocket Option. Локальный доступ расширения при необходимости разреши один раз в браузере.

Если брокер не передал понятный ID или валюту, модуль попросит подтверждение. Указывай только ID своего открытого аккаунта и подтверждай USD только для долларового счёта. Профиль сохраняется для следующих обновлений; реальный и деморежимы разделены.

## Если данных нет

- Проверь версию **0.4.3**, актуальный адрес и недавнее «Сервер принял…». Отдельно показан статус сборщика; число его заданий не равно числу готовых графиков.
- Закрытый канал ждёт каталог нового соединения. Старые свечи и цены другого канала не смешиваются с новым графиком. Это не требование заново подтверждать ID.
- Сохранённый профиль времени — UTC либо Pocket Option UTC+2 → UTC. Он не подбирается автоматически; старые метки не переносятся на текущее время. Не меняй профиль без измеренной причины.
- Одна повреждённая свеча больше не блокирует остальные. Старый разрыв перед 80 хорошими свечами не блокирует их; разрыв внутри последних необходимых свечей по-прежнему блокирует сценарий.
- При кратком сбое доставки история повторяется до трёх раз с исходными метками. Старые котировки не становятся свежими.
- Работающий модуль восстанавливает связь со вкладкой после перезапуска worker. Входящие сообщения продолжают очередь при замедлении таймеров страницы. Если браузер полностью выгрузил вкладку или сокет закрылся, нужно восстановить сам терминал.

## Проверки сборки

`SHA256SUMS.json` проверяется при запуске; CMD сохранены в ASCII с CRLF. Новые поля базы добавляются без удаления личных данных.

```text
python -m unittest -q
node check_connector.js
node check_connector_worker.js
node check_market_scan.js
node check_scan_recovery.js
node check_scanner_tab.js
node check_local_link.js
python check_native_chart_scan.py --warm
python check_native_chart_scan.py --expiry 5
python check_native_chart_scan.py --expiry 10
python check_native_chart_scan.py --expiry 15
python check_stream_resilience.py
python check_fast_collection.py --no-tab-timers
python check_quote_recovery.py
python check_partial_scan.py
python check_short_history.py
python check_ai_scan_ui.py --provider lunaroute
python check_strategy_ui.py
```

UI-проверки требуют Chromium и Playwright. Тесты используют временные базы, тестовые подписи, локальный HTTP/SSE-провайдер и брокерские фикстуры. Проверяется настоящий код API, соединителя и клиента модели; это не соединение с реальным брокером или платной моделью и не проверка прибыльности. Нативная загрузка расширений в управляемом Chromium этой среды запрещена политикой администратора; настоящий поток проверяется после установки на устройстве владельца.
