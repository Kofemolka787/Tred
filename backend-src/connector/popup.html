TRED CONNECT

Войди в Pocket Option самостоятельно. Модуль читает входящие данные; пароль не нужен.



Для подтверждения Pocket ID открой это расширение прямо на вкладке с нужным графиком Pocket Option.



  
Подтверди Pocket ID

  

  Баланс поступает, а Pocket ID нужно проверить. Скопируй номер из своего профиля Pocket Option.
  

    
    
    
  

  Номер сохраняется в этом браузере для выбранного режима. Новые изменения баланса передаются автоматически. При входе в другой Pocket-аккаунт смени сохранённый ID.
  






Изменения видимого баланса отслеживаются автоматически; контрольная проверка — каждые 5 секунд. Окно расширения можно закрыть.


  

  

  
  
  Подтверждай только валюту, которую видишь на своём счёте Pocket Option. Подтверждение USD сохраняется для этого ID и режима; новые изменения баланса передаются автоматически.
  





  

  
  Если котировки опережают часы на 7200 секунд, выбери UTC+2. Это формат времени источника для котировок и свечей. Проверка свежести остаётся включённой.
  




Модуль 0.3.8
После обновления модуля обнови вкладку Pocket Option. Держи компьютер, сервер и график открытыми. Если Windows показывает неверное время, используй «Синхронизировать сейчас» в настройках часов.
