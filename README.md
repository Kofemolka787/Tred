# TRED Mini App

TRED v0.2 — Telegram Mini App interface for @Tr1edBot_bot.

Open https://kofemolka787.github.io/Tred/ or use the application button in the bot. The interface is open to every account, on phone and desktop, with no intermediary advertising page.

This release focuses on design: market and pair selection, four tabs, profile and local preferences. Trading logic, live signals and cross-device synchronization are deferred. No results or account connections are fabricated.

This public repository contains static UI files only: no bot tokens, account sessions, private access lists or databases.
